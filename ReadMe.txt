----------------- | How To Use Soundboard | -----------------

So Get A .mp3 File, Then Go To Https://Audio.Online-Convert.Com/Convert/Mp3-To-Wav,
Then Convert Your .mp3 File To .wav. Once You Have Obtained The .wav File, You Copy It.
Then, Go To Android, Data, com.AnotherAxiom.GorillaTag, Files, You'll See A "Sounds" Folder.
Go Inside It, Paste In Your .wav File. Then Go In-Game, Then Go To The Soundboard Category,
Then Press The Button That Says Word-For-Word "Reload Sounds" [Might Have To Press More Than Once].
Then It Should Appear, And You Have A Working Soundboard!
